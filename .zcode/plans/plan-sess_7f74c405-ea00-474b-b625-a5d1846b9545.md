## 目标
1. **全局永久 IP 黑名单**：op-admin 的 `/api/*`（含 admin、client）和 `/sdkapi/*`（登录）都检查，命中即 403，永久不过期。`162.14.71.15` 手动写入即永久封。
2. **`/api/client/*` 频率限制**：同 IP 30 次/分钟，超限返回 429；持续超限触发封禁阈值后写全局黑名单 24h（之后该 IP 任何接口都 403）。
3. **日志带封锁原因**：每条封锁日志说明"触发了什么导致封锁"（不只说锁类型，还带上可读原因）。

## 改动文件（3 个）

### 1. `apps/op-admin/server/utils/loginRateLimit.ts`（新增工具）
复用 `getClientIp`/`getRedisCluster`/`formatWait`，新增：

- **全局黑名单**（永久）：
  - key `global:ip_blacklist:<ip>`，存值=封禁原因（如"手动封禁"/"客户端接口超频"）
  - `checkGlobalBlacklist(ip)`: EXISTS 检查，命中返回 `{locked:true, reason:'global_blacklist', message:'<存储的原因>'}`（读 key 值作为原因）
  - `banIpPermanently(ip, reason)`: `SET key reason`（不带 EX，永久）
  - `banIpTemporarily(ip, reason, ttl=86400)`: `SET key reason EX ttl`（24h）
  - `unbanIp(ip)`: DEL

- **`/api/client/*` 频率限制**（30 次/分钟）：
  - `checkClientRateLimit(ip)`: INCR `client:ip_rate_cnt:<ip>`，首条 EXPIRE 60；返回 `{limited:true, count, message:'客户端接口请求超频(N次/分)'}` 当 count > 30

- 常量：`CLIENT_RATE_LIMIT=30`、`CLIENT_RATE_WINDOW=60`、`CLIENT_BAN_TTL=86400`
- 全部 try/catch，Redis 异常 fail-open

### 2. `apps/op-admin/server/api/[...].ts`（withLogging 入口加检查 + 带原因日志）
在 `withLogging` 访问日志后、业务调用前插入（所有 `/api/*` 路由都经过 withLogging）：
```ts
const ip = getClientIp(headers as Record<string,string>);  // 升级 IP 提取
// 1. 全局黑名单（所有接口，命中带原因）
const gbl = await checkGlobalBlacklist(ip);
if (gbl.locked) {
  setResponseStatus(event, 403);
  console.warn(`[黑名单] ${method} ${url.pathname} IP=${ip} 已封禁，原因：${gbl.message}`);
  return { success:false, message:'该 IP 已被封禁', data:null };
}
// 2. /api/client/* 频率限制
if (url.pathname.startsWith('/api/client/')) {
  const rl = await checkClientRateLimit(ip);
  if (rl.limited) {
    setResponseStatus(event, 429);
    console.warn(`[限流] ${method} ${url.pathname} IP=${ip} ${rl.message}，封禁24h`);
    await banIpTemporarily(ip, `客户端接口超频(${rl.count}次/分)`, CLIENT_BAN_TTL);
    return { success:false, message:rl.message, data:null };
  }
}
```
- import: `getClientIp, checkGlobalBlacklist, checkClientRateLimit, banIpTemporarily, CLIENT_BAN_TTL`

### 4. 手动封禁 `162.14.71.15`
- **Redis 命令**（立即可用）：`redis-cli SET global:ip_blacklist:162.14.71.15 "手动封禁-恶意刷接口"`（不带 EX=永久）
- **小脚本** `apps/op-admin/部署/scripts/ban-ip.js`：`node ban-ip.js 162.14.71.15 [其他ip...]`，调 `banIpPermanently(ip, '手动封禁')`
